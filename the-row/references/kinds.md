# Which object to open

Use this after you have the question. How to bind a cell lives in `SKILL.md`. Do not add new calls here.

| Kind | Open this | Do not use instead |
|---|---|---|
| Charity spend | The functional expense table or the audited spend note. Program vs management vs fundraising. | The homepage ratio, a badge, or "90 cents" in the email. |
| Company money | The statement that matches the question (income, cash, balance), for the stated period, in the filing. | A press note, a tweet, or an old deck. |
| Study result | The results table for that outcome, that group, that time. | The abstract, the press office, or a graph with no axis text. |
| Public rate | The series table from the office that publishes it, plus the notes. | A chart in a post with no source line. |
| Product spec | The current spec table from the owner. | A store listing that copied the number. |

Charity pages often show one "program" percent. Check what sits in that percent (grants only, or also staff). If the note does not say, the cell is not settled.

Company filings often show a current period and a prior period. Say which column you used.

Papers often have many tables. Match the outcome name in the question to the outcome name in the table. Close is not enough.

# How a hinge hides

Open this when the hinge left is a number, a rate, a study, a cause story, or a pile of sites. The calls (Take, Wait, Walk) live in `SKILL.md`. Do not add new calls here.

Find the hide. Write the cheap check. Get that. Ignore extra words that are not the hinge.

| Hide | What it is doing | Cheap check |
|---|---|---|
| Bound sold as usual | "Up to" or "as low as" is doing the work of "what you should expect." | The middle result, or who qualifies, from the party that would get in trouble for publishing it. |
| Rate with no starting size | "Doubled," "50% more," "record" with no starting count or group. | The starting count, the group, and what counts as the event. |
| Easy stand-in | They measured an easier thing than the result the move cares about. | Name the stand-in and the real result. Get the real result if it exists. |
| Picked window | They picked a range because it looks good. | The windows next to it, or the time span they set in advance. |
| One path, many causes | X happened, then Y, so X did it. | What else changed in the same window. What the group that did not do X did. |
| Number with no owner | A figure with no data file and no publisher who would fix a mistake. | Who keeps this series. If nobody, the hinge is not settled. |
| Many pages, one source | Lots of URLs, one press note or one blog. | The first page. Count sources, not URLs. |
| Extra words in a hinge costume | Timer, logo wall, customer quote, "trusted by." | Ask if the move still makes sense if this is false. If yes, drop it. |

Who owns the record:

- Whoever would be fined, sued, or in trouble at work if the number is wrong.
- For a product: the owner's current docs, then a direct test.
- For a public rate: the office that publishes the series, plus its notes.
- For a study: the results table, not the press office.

If the person making the claim is the only source, write "they say" and do not Take on that alone when the move is costly.

# Hinge

A sales page, post, or pitch wants you to do something: buy, share, believe, vote, sign, donate, panic. Most of the words are extra. Find the claim that would change the choice, open the record that can break or back it, and give a call.

Do not grade every sentence. Do not name sales tricks instead of checking.

## When to Use

- User wants to know if an ad, post, pitch, memo, or viral claim should change what they do.
- User says "what's the hinge", "what actually matters", "should I act on this", "check this before I buy / share / sign."
- User pastes a URL or page and asks if they should act on it.
- The message is long, sure of itself, or emotional, and they need the one check that matters.

Don't use for:

- Reading lying from voice, video, eye contact, or confidence.
- Wide research with no choice attached.
- Writing ads.
- Medical, legal, or money advice. You may check the hinge. A person owns the choice.

## Need first

- A way to search the web and open a page or file. If you cannot open anything this turn, the call is Wait. Say what you could not open.
- If the claim is a screenshot or chart, read the image they gave you. Do not invent text that is not in it.
- No extra software.

## Steps

Start with one message: paste, URL, screenshot, or file. If the user gave a URL, open it before you judge. If they named a source they did not attach, open it before you make a call. If you split the hunt, treat other notes as leads and open every URL yourself.

### 1. Name the move

One short phrase: buy this, share this, sign this, believe this rate, take this job, donate, dump the stock. If you cannot name the move, ask. Do not check a page with no goal.

### 2. Write the refusal

One sentence: "I would not do this if ___." The blank is the first hinge.

### 3. Keep only what flips the move

Pull a few claims out of the message. Drop any claim that can be wrong while the move still makes sense. Timers, fancy logos, customer quotes, and "everyone knows" almost never make this cut.

At most two hinges. If you have five, you have not cut.

If nothing you can check is left and the move is costly, the call is Walk. Or Wait, if the user can get the missing record cheaply.

Open `references/hides.md` when the hinge is a number, a rate, a study, a story about causes, or a pile of sites saying the same thing.

### 4. Name the cheapest way to break it, then go get it

For each hinge, write the smallest fact that would make the move a bad idea. Get that fact this turn.

Who gets in trouble if this number is wrong? Check that party, the official body over them, or the data they owe. Not a copy of their copy.

**Hard rule.** Take, and Walk because the hinge failed, both need a URL and a quote you opened this turn. If not, Wait. A memory is not a source.

A dead link is only about that link. Search the publisher's own site before you decide the record is gone.

For a table or chart, quote the row or figure labels from the file. If you cannot tell which number is which, Wait.

### 5. Make the call

| Call | When |
|---|---|
| Take | The hinge holds for this move. |
| Wait | You can check it, but you have not yet, or a person has to own the risk. |
| Walk | The hinge failed, the usual-case reading fails, or the move is costly and nothing you can check is left. |

"Up to" or "as many as" used as if it were the usual result is a failed usual-case hinge. You do not need to call the sentence a lie. Walk or Wait, based on whether you can still find the usual number.

### 6. Report

Use `templates/report.md`. Keep it short.

High risk (money, health, law, identity, a step you cannot undo): add **Left unchecked** so the user sees what you did not chase.

Example:

> **Move:** Buy the course tonight.
> **Hinge:** Finishing it gets a usual student a job in 90 days.
> **Cheap check:** The school's job rate, what "placed" means, and how many starters finish.
> **Call:** Wait. The ad only gives an "up to" salary from unnamed old students.

## Watch for

- Grading every claim in the message. That is a different job.
- Naming a sales trick and stopping.
- Picking a hinge the user does not care about (user count when they asked if export works).
- Refusing Take on a spec you opened that matches, just because the rest of the page is sales talk.
- Making up a hinge the message did not use.
- Filling "What I opened" from memory.

## You're done when

- The move is named.
- There are one or two hinges, each with a cheap check.
- Take, or Walk because it failed, cites a URL and quote from this turn. If not, the call is Wait.
- The report is short.
- Next is one action, or "none" if the call already settles it.
